**IP-SAKTI Sahayak** is an authoritative, multi-agent AI assistant engineered specifically for Ayurvedic innovators, AYUSH MSMEs, bio-researchers, practitioners, and startups. It delivers verifiable legal and regulatory guidance grounded in primary Indian statutes, official pharmacopoeias, and international trade treaties—with **evidence-validated citations**, strict jurisdictional separation, and instant escalation to certified human IP facilitators.

---

## 🏛️ Authoritative Statutory Foundations

Every guidance generated by IP-SAKTI is dynamically grounded in verified primary statutory sources:
1. **The Patents Act, 1970 (as amended)** — Section 3(p) Traditional Knowledge exclusions, Section 3(d) Enhanced efficacy, Section 3(j), Section 10(4)(d)(ii) mandatory biological origin disclosure, and Section 25(1)(k) pre/post-grant opposition.
2. **The Biological Diversity Act, 2002 & Amendment Act, 2023** — Section 3 foreign access approvals, Section 6 mandatory National Biodiversity Authority (NBA) prior approval before patent grant, Section 7 State Biodiversity Board (SBB) prior intimation, Section 21 equitable benefit sharing, and Section 40 Normally Traded Commodities (NTC) exemptions.
3. **The Drugs and Cosmetics Act, 1940 & Rules, 1945** — Chapter IV-A (ASU Drugs), Rule 158B licensing proofs for Classical vs Patent/Proprietary (P&P) Ayurvedic medicines, and the First Schedule list of authoritative classical texts.
4. **FSSAI (Ayurveda Aahar) Regulations, 2022** — Regulations 3, 4, and 6 governing health claims, labeling mandates, and permitted Rasayana wellness formulations.
5. **International Export & Treaties** — US FDA DSHEA (21 CFR Part 111 cGMP and Structure/Function claims), EU THMPD (Directive 2004/24/EC), and the historic **WIPO Treaty on Intellectual Property, Genetic Resources and Associated Traditional Knowledge (2024)**.

## 🚀 Key Features

1. **Dynamic Database Ingestion & Live Citations**: Statutory data is loaded from structured JSON datasets and private document uploads directly into database records (`DocumentChunk`, `SourceRegistry`) with instant index reload.
2. **Dynamic Hybrid Retriever**: Multi-factor lexical BM25 and vector search with query token coverage weighting, strict jurisdiction pre-filtering, and authority ranking.
3. **Claim-Level Grounding & Verification**: Post-generation citation engine that extracts individual claims, calculates token overlap against evidence chunks, and eliminates ungrounded statements.
4. **Multi-turn Clarifying Questions**: Formulations are disambiguated across Classical, P&P, Ayurveda Aahar, and Cosmetic categories with 3-language clarifying questions (EN, HI, TA).
5. **Private Formulation Document Vault**: Isolated multi-tenant namespaces (`USER_{user_id}`) with cryptographic SHA-256 validation, OCR numeric preservation, and prompt injection defense.
6. **Algorithmic Confidence Scorer**: Dynamic confidence calculation factoring in authority hierarchy, retrieval relevance, and citation grounding with automated safe abstention.
7. **Human Facilitator Escalation**: Instant one-click ticket dispatch with pre-filled AI claim summaries to registered IP attorneys.

## 🛠️ Quickstart

### Prerequisites
- Python 3.10+
- Node.js 18+
- Docker & Docker Compose (optional for containerized deployment)

### 1. Backend Setup
```bash
# Clone repository
git clone https://github.com/your-org/ip-sakti-sih2026.git
cd ip-sakti-sih2026

# Create virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r backend/requirements.txt

# Run initial live ingestion and seeder
python backend/app/ingestion/seeder.py

# Start FastAPI server
uvicorn backend.app.main:app --host 0.0.0.0 --port 8000 --reload
```
API Documentation will be live at: `http://localhost:8000/docs`

### 2. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
Web application will be live at: `http://localhost:3000`
