## 🔒 Compliance & Data Protection

AYURA is engineered according to the standards of the **Digital Personal Data Protection (DPDP) Act, 2023** (India) and government deployment specifications:
1. **Zero Secret Leaks**: API keys, credentials, and tokens are strictly configured via environment variables and never logged or committed.
2. **Audit Logging**: All statutory Q&A and classification sessions record tamper-resistant audit logs without storing personally identifiable information (PII).
3. **Statutory Integrity**: Retrieval-augmented generation strictly constrains outputs to verified legal corpus chunks to prevent misinformation or statutory hallucination.

## 🚨 Reporting a Vulnerability

If you discover a security vulnerability within this project, please **do NOT report it through public GitHub issues**.

Instead, please send a report to the repository maintainer:
- **Email**: Contact via GitHub Profile [@SHREESABARI-5143](https://github.com/SHREESABARI-5143)

Please include:
- A description of the issue and potential impact.
- Step-by-step instructions or proof-of-concept to reproduce the vulnerability.
- Your recommended remediation (if available).

We will acknowledge receipt within 48 hours and work with you to patch and disclose responsibly.
